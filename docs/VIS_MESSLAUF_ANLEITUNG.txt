vis-Image auf der Flotte messen: Anleitung zum Selbststarten
=============================================================
Stand: Branch claude/cool-keller-22vw04, Commit e2916c1 oder neuer (Image-Attestierung ist gueltig).
Wichtig: Das Token steht NUR in deiner eigenen Shell. Nicht in den Chat, nicht in eine Datei im Repository.

Kosten (aus dem Preflight): geschaetzt 6,00 EUR/h bei Obergrenze 8 EUR/h, Kaltstart bis etwa 1,02 EUR,
Testfenster 28 Minuten, damit hoechstens etwa 3,82 EUR. Acht Instanzen werden gemietet, danach mit `down` wieder entfernt.

0) Voraussetzungen (auf deinem Rechner oder Server mit Python 3, git und Zugriff auf Vast)
   git clone <repo>; git checkout claude/cool-keller-22vw04; git pull
   Vast-API-Schluessel als VAST_API_KEY in der Umgebung (Konsole -> Account -> API-Schluessel).

1) GitHub-Token nur zum Lesen anlegen
   GitHub -> Settings -> Developer settings -> Personal access tokens -> Tokens (classic) -> Generate new token
   Nur Haken bei: read:packages     Laufzeit: 7 Tage

2) Variablen setzen (in der Shell, Werte selbst einsetzen)
   export GHCR_USERNAME='kainplanmusic'            # oder dein GitHub-Benutzername
   read -rs GHCR_PASSWORD; export GHCR_PASSWORD    # Token einfuegen, Eingabe bleibt unsichtbar, dann Enter
   export R2_ACCOUNT_ID='...'
   export R2_ACCESS_KEY_ID='...'
   read -rs R2_SECRET_ACCESS_KEY; export R2_SECRET_ACCESS_KEY
   export R2_ENDPOINT='https://<R2_ACCOUNT_ID>.r2.cloudflarestorage.com'
   export AI_POD_TOKEN="$(python3 -c 'import secrets;print(secrets.token_urlsafe(48))')"
   export VAST_STATE_DIR="$HOME/vast-fleet"        # Zustand und Zertifikate, nicht ins Repository legen
   export VAST_PLAN_OFFER_LIMIT=40                 # wenige Suchzeilen, schont das Tageslimit von Vast

3) Plan erzeugen (nur lesend, mietet nichts)
   python3 scripts/vast-fleet-plan.py --output vast-plan.json --region global \
     --transfer-inventory deploy/vast/transfer-inventory.json --image-sizes deploy/vast/image-sizes.json

4) Vorpruefung (mietet nichts)
   python3 scripts/vast-pods.py preflight --plan vast-plan.json
   Erwartet: "instancesCreated": 0, "positiveCredit": true, "estimatedTotalEurPerHour" etwa 6, "hourlyCeiling": 8

5) Flotte starten (HIER ENTSTEHEN KOSTEN)
   python3 scripts/vast-pods.py up --yes --plan vast-plan.json --images deploy/vast/images.json
   - Bricht ab, wenn der vis-Host kein NVENC hat: Der Host wird 7 Tage gesperrt, alles wird aufgeraeumt.
     Dann einfach Schritt 5 noch einmal ausfuehren (anderer Host).
   - Bei jedem anderen Fehler raeumt das Skript selbst auf. Zur Sicherheit danach pruefen: python3 scripts/vast-pods.py status

6) vis messen
   python3 scripts/vis-pod-measure.py --state-dir "$VAST_STATE_DIR" --seconds 20
   Optional mit echten Medien: --media media.json  (Liste [{id, kind, url}] mit frisch signierten https-Links)
   Ergebnis: Tabelle und "$VAST_STATE_DIR/vis-pod-measure.json" (keine Secrets darin).

7) Flotte sofort wieder entfernen (Pflicht, sonst laufen Kosten weiter)
   python3 scripts/vast-pods.py down --yes
   python3 scripts/vast-pods.py status        # soll keine Instanzen mehr zeigen
   Ausserdem in der Vast-Konsole unter Instances kontrollieren, dass nichts mehr laeuft.

8) Aufraeumen
   unset GHCR_PASSWORD R2_SECRET_ACCESS_KEY AI_POD_TOKEN
   GitHub-Token loeschen (Settings -> Personal access tokens -> Delete), falls nicht mehr gebraucht.

Was ich danach mit dem Ergebnis mache: schick mir NUR die Datei vis-pod-measure.json (oder den Tabellenausschnitt aus Schritt 6).
Darin stehen keine Zugangsdaten. Ich werte sie aus und trage sie in docs/VIS_GPU_MESSUNG.md ein.
Zum Vergleich (Testaufbau auf einzelner 4090, gleiche Karte, NVENC): 1080p@30 29,5 fps, 1440p@30 28,9 fps, stop() unter 0,6 s.
